三、为什么从 MailerLite 换成 Brevo

你的要求里指定了邮件 1 的主题 Confirm your ChinaSourcing subscription 与正文内容。核实官方文档后发现 MailerLite 免费版不能编辑 Double Opt-in 确认邮件（其帮助中心写明该功能仅付费套餐可用），也就是免费版发不出你要的这封信。这属于"功能不符合需求"，按约定先报告而不是擅自切换；经你确认后改用 Brevo。

对比项MailerLite 免费版Brevo 免费版
发信额度12,000 封/月（2026-06 起下调）300 封/天，约 9,000 封/月
订阅者上限250 人（免费版）10 万联系人上限，按发信量计费
Double Opt-in新建表单默认开启可选开启
确认前是否发资料未确认只收确认信未点击不进列表
自定义确认邮件仅付费套餐支持自定义模板 + 确认链接
营销自动化3 条，每条 5 步包含，上限 2,000 联系人
品牌水印无免费版带 Brevo 标识
结论缺"自定义确认邮件"这一项满足全部需求，改用此方案

Brevo 的两个已知代价：免费版邮件带品牌水印；第三方测得的 Gmail 进箱率约 72%（共享 IP 所致，换任何一家入门套餐都类似，只能靠域名认证与预热改善）。

仍然没有切换技术路线：两家都是官方托管表单 + 自动化，本站不接后端、不存数据、不放密钥。换成 Brevo 只影响你在后台点哪里，不影响站点结构。

五、订阅流程与"两态"设计

站点没有后端、没有数据库，也不允许在前端放密钥，所以订阅动作不能在站内完成。组件因此只有两种状态，由 site.ts 里一个字段控制：

状态行为
未配置
当前状态		 本地做格式校验与同意勾选校验，通过后明确告诉访客"没有连接邮件服务，什么都没有发送、也没有存储"。不出现任何成功提示，不冒充已订阅。
已配置 取得 Brevo 托管表单地址后填进 hostedUrl，按钮改为跳转到该表单页。邮箱、同意勾选、Double Opt-in、确认邮件全部在 Brevo 侧完成，本站只负责把人送过去。改一行配置即可上线，不需要改组件逻辑。

为什么不自己写一个 POST /subscribe：那需要一个能保管密钥的服务端。纯静态站做这件事只有两条路——把密钥写进前端（绝不允许），或者加后端（超出本阶段范围，且会带来费用与运维）。托管表单是唯一既真实又不需要后端的方式。

注：确认前不给资料这一条，靠的是 Brevo 的机制（未确认的订阅者不在列表里，自动化不会触发），不是靠本站判断——本站没有能力判断，所以也不声称。

七、资料怎么交付，以及保护边界在哪里

计划的做法：在 Brevo 邮件编辑器里用 Insert File 上传两份文件，由 Brevo 托管，链接只出现在邮件正文中，不出现在网站页面上。

必须说清楚的三件事：

  1. 这不是会员鉴权。没有登录、没有身份校验、没有限时签名链接。邮件里的下载地址一旦被转发，拿到的人就能下载。
  2. 因此不会把它称作"安全私密链接"。准确说法是"通过邮件发送的下载地址"。
  3. 公开直链已于 2026-11-20 撤下。早前为让审查方读取，两份文件被放到 GitHub Pages；现在三份副本（supplier-comparison-spreadsheet.xlsx、supplier-comparison-spreadsheet-v1.0.xlsx、common-chinese-english-sourcing-terms.pdf）已从公开仓库删除，三个 URL 实测均返回 404。内部原件与备份逐字节保留，见 resources/subscriber/published-copies-MANIFEST.json。
  4. 但还不能说"已经受保护"。删除的是公开副本，交付靠邮件附件；邮件附件本身可被转发。要真正的访问控制（限时签名链接、会员会话），仍需后端或付费功能，本阶段没有做，也没有声称做了。

要做到真正的"只有订阅者能下载"，需要其中一种：服务商侧的门禁（部分平台付费版才有）、带时效签名的对象存储链接、或一个能校验会话的后端。这三样都要么花钱要么加后端，按你的要求只报告、不擅自实施。

文件体积参考：工作簿 37.3 KiB，术语手册 1.4 MiB（25 页）。两者都在常见邮箱的附件上限内，可以直接附件，也可以走托管链接。

八、隐私政策：这次刻意没有改

现有隐私政策写的是"表单尚未连接邮件服务商"。这句话此刻仍然成立——改成一个还没发生的状态（"由 Brevo 处理"）反而会说假话。所以本阶段不动它。

接通当天需要一次性补上四项，草稿要点如下：

  • 收集什么、为什么：只收集邮箱地址，用于发送两份资料与你同意的采购资讯
  • 谁在处理：Brevo（法国公司，数据存于欧盟），需写明其为数据处理者，并附其隐私政策链接
  • 如何退订：每封邮件底部均有退订链接，点击后立即停止后续发送
  • 如何删除：可通过联系页提出删除请求，删除后不再保留该地址

另外三条边界已经守住：Ask a Question 的提交者不会被自动加进名单（该功能尚未开发）；下载免费资料不会被当作订阅同意（三份免费 PDF 无需邮箱）；不会购买或导入来源不明的邮箱名单。

十三、给审查者的三个问题

  1. 托管表单算不算"真实可用的订阅系统"？本站只把人送到 Brevo 的表单页，站内不承接提交。这样做合规、无密钥风险，但转化路径多一跳，且站点无法回显"已订阅"状态。

  3. 资料直链要不要撤？撤掉后审查方需要另找入口（可改用网页版 workbook.html），但订阅门槛才真正成立。
