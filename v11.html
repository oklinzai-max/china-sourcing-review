1. Quotation Comparison

Comparable? 改名为 Core Terms Match，并新增 Additional Checks 列

为什么改：四项一致只是"核心条款一致"，不代表两份报价整体可比。原名容易被误读成"全部条件都可比"。

版本公式 / 内容
v1.0=IF(COUNTA($C$5,$E$5,$G$5,$I$5)<4,"Set the reference block above",IF(COUNTA($D8,$E8,$F8,$G8)=0,"",IF(AND($D8=$C$5,$E8=$E$5,$F8=$G$5,$G8=$I$5),"Comparable","Not comparable — check specification, quantity, currency or Incoterm")))
v1.1=IF(COUNTA($C$5,$E$5,$G$5,$I$5)<4,"Set the reference block above",IF(COUNTA($D8,$E8,$F8,$G8)=0,"",IF(AND($D8=$C$5,$E8=$E$5,$F8=$G$5,$G8=$I$5),"Match","No match — check specification, quantity, currency or Incoterm")))

R 列标题写明还要人工核对：packaging, payment terms, destination / delivery place, taxes, quote validity, extra charges。

2. Sample Tracking

新增 Expected Arrival Date，逾期改为按预计到货日判断

为什么改：14 天对空运、海运、快递完全不适用；同一条规则套在所有人身上，等于没有判断。

版本公式 / 内容
v1.0=IF(OR($F5="",$H5<>""),"",IF($F5+14<TODAY(),"No arrival after 14 days — chase it",""))
v1.1=IF(OR($F5="",$I5=""),"",IF($H5<>"",IF($H5<$I5,"Arrived early",IF($H5=$I5,"Arrived on time","Arrived late")),IF(TODAY()>$I5,"Overdue — not arrived","In transit")))

Days in transit 仍为 =H-F（发运日到到货日），未受影响。新列插入在 Arrival date 之后，数据验证与条件格式已同步重映射。

3. Supplier Evaluation

八项未填齐显示 Incomplete；权重不等于 100% 时报警并拒绝出分

为什么改：空分当 0 参与加权，会把"还没问"变成"很差"，直接压低总分并影响排序。

版本公式 / 内容
v1.0=IFERROR(IF(SUMPRODUCT($C$4:$J$4)=0,"",IF(COUNTA(C6:J6)=0,"",SUMPRODUCT(C6:J6,$C$4:$J$4)/SUMPRODUCT($C$4:$J$4))),"")
v1.1=IF(COUNTA(C6:J6)=0,"",IF(COUNTA(C6:J6)<8,"Incomplete — "&COUNTA(C6:J6)&"/8 scored",IF($K$4<>100,"Weights ≠ 100% — cannot score",SUMPRODUCT(C6:J6,$C$4:$J$4)/100)))

B4 由静态文字改为公式：=IF($K$4=100,"Weights total 100%","Warning: weights total "&$K$4&"% — must equal 100%")，权重一动就会提示。

4. Supplier Comparison

Landed cost per unit 改为 Estimated Landed Cost per Unit，并加币种与重复计入说明

为什么改：这个数是估算，不是供应商报的到岸价；不同币种直接相加、或把已含在报价里的费用再加一次，都会算出错的成本。

版本公式 / 内容
v1.0表头：Landed cost per unit
v1.1表头：Estimated Landed Cost per Unit；公式未变：=IFERROR(IF(OR($M5="",$N5=""),"",$N5+($AB5+$AC5)/$M5),"")

A2 说明追加：单价 / 运费 / 税费必须同币种；若某项已含在报价里，不要再加到运费或税费列。

必须说清楚的：没有在 Excel 或 WPS 里实测

本轮全部验证都在本机表格引擎里完成（@tencent/tencent-docs-ai-engine 的 editor_sdk）：公式由引擎真实计算，条件格式与数据验证从文件 XML 里读回核对。

但没有在 Microsoft Excel 或 WPS 中打开验证过。本机未安装 Excel；WPS 已安装，但沙箱禁止 COM 实例化（Ket.Application），无法程序化驱动。因此以下情况属于"未验证"：Excel 对公式的兼容性、条件格式在 WPS 里的配色、插入列后列宽与打印区域的观感。

用到的函数只有 IF / COUNTA / SUMPRODUCT / IFERROR / TODAY / AND，均为 Excel 2007 起可用；未使用动态数组、LAMBDA、VBA 或宏。
